# 🚐 配布ナビサポーター (スプリット画面＆Excel直接連携版)

Androidスマートフォンの「画面分割（スプリット機能）」を活用し、**「上半分にGoogleマップナビ」「下半分にワンタップ配布チェック」** を並べて爆速で配達できる専用アプリです。

---

## 🌐 インストール用URL（スマホで開くだけ）
**https://tomos560807.github.io/yoshimachidenki-delivery/**

---

## 📱 画面分割（スプリット）での現場のイメージ

- **画面の上半分**：Googleマップが常にカーナビとして目的地を案内
- **画面の下半分**：次のお客さんカードが表示され、特大の **「🎁 手渡し」「📬 投函」「⚠️ 不在」** をワンタップ！
- 配布すると自動で次のお宅に切り替わり、**「🧭 Googleマップで案内開始」** を押せば上半分のGoogleマップのナビ先が瞬時に切り替わります。

---

## 🚀 準備はこれだけ！超かんたん 2ステップ

面倒なプログラム設定やGASのデプロイは**一切不要**になりました。

### 【ステップ 1】アプリを開く
スマホのブラウザ（ChromeやSafari）で上記のURLを開き、メニュー（︙）から **「ホーム画面に追加」** または **「アプリをインストール」** を押します。

---

### 【ステップ 2】Excelファイルを選ぶ（複数案件の作成対応！）
1. アプリ右上の **「📁 案件切替/Excel」** を押します。
2. **「➕ 新しいExcelを追加して案件を作成」** をタップし、配りたいExcelファイル（例: `2025年カレンダー.xlsm` や `春の合展チラシ.xlsx`）を選びます。
3. 案件名（例：「2025年カレンダー」「春の合展」など）を入力すると、**即座にその案件としてスマホ内に保存・管理**されます！

---

## 📁 複数プロジェクト（案件別管理）の使い方

- **いつでもワンタップで案件切替**:  
  ヘッダー下の「📁 案件名 ▾」をタップするだけで、保存されている案件の一覧が表示されます。「開く」を押せば、別の案件へ瞬時に切り替わります。
- **配った記録も案件ごとに完全独立**:  
  カレンダーの配達途中で合展チラシに切り替えても、それぞれの「手渡し・投函・不在」の記録は案件ごとに自動保存されます。
- **案件名の変更・削除**:  
  案件一覧から「✏️ 名前変更」や「🗑️ 削除」も片手で簡単に行えます。

---

## 💻 PC側との共有（結果の反映方法）

1. 配布作業が終わったら、右上の **「📁 案件切替/Excel」** を開きます。
2. **「📥 この案件の更新Excelを書き出す」** を押します。
3. 配布済み（A列に1、T列に完了時刻、手渡し/投函の記録）が書き込まれた最新のExcelファイル（例: `配布結果_2025年カレンダー配布_2026-XX-XX.xlsx`）がダウンロードされます。
4. Googleドライブのフォルダに保存すれば、**お店のパソコン側にも自動で同期**されます！
